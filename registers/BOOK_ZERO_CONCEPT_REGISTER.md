## 1. WHAT THIS REGISTER IS

A **controlled list of concept identifiers**, each linked to the exact source section in Book
Zero where the concept appears.

| This register may | This register may not |
|---|---|
| Assign a stable ID to a concept | Define a concept |
| Cite the source section where a concept appears | Interpret, expand, or narrow it |
| Record that a concept is a founder term or a governance term | Grant a concept authority |
| Record a concept's status | Approve a concept |
| Mark a concept **Unresolved** | Resolve it by assumption |

**An ID is an address, not a definition.** The definition of any concept is whatever Book Zero
says it is, in the section cited. Where this register and Book Zero disagree, **Book Zero
governs.**

**This register adds nothing to Book Zero.** It is an index. It was built by reading the
extraction, not by inventing content.

---

## 2. ID FORMAT

```
BZ-<class>-<number>
```

| Class | Meaning |
|---|---|
| `BZ-F` | Foundational concept — a principle, discipline, or value |
| `BZ-A` | Access concept — participation, dignity, entry |
| `BZ-J` | Justice concept — rights, responsibility, consequence |
| `BZ-S` | System concept — a structure or mechanism named in Book Zero |
| `BZ-T` | Founder term — a word or phrase carrying founder-specific meaning |
| `BZ-X` | Contested or unresolved concept — recorded, not decided |

IDs are **stable and never reused.** A retired concept keeps its ID and is marked `Superseded`.

## 3. STATUS VOCABULARY

Per `05_evidence_status_and_truth_taxonomy.md`:

| Status | Meaning |
|---|---|
| `Founder-defined` | The founder's own term, with meaning fixed in Book Zero |
| `Founder-discovered` | Recovered from the creation process; recorded in Book Zero |
| `Existing` | The concept appears in Book Zero; this register does not verify completeness |
| `Unresolved` | The concept's meaning or boundary is not settled in Book Zero |
| `Disputed` | Conflicting evidence or usage exists |
| `Proposed` | Not yet in Book Zero; awaiting founder authoring |

## 6. WHAT THIS REGISTER DOES NOT DO

- It does **not** define any concept. Book Zero defines them.
- It does **not** modify Book Zero or any part of the manuscript.
- It does **not** modify any Frozen document.
- It does **not** approve the extraction boundary.
- It does **not** approve Chapter 35.
- It does **not** grant authority to any concept.
- It does **not** verify that the concept list is complete.

**Completeness is Unknown, not Claimed.** This register was built from the 228 numbered
subsections of the extraction. Concepts stated in prose without a numbered heading are **not
captured**. That is a known limitation, stated rather than hidden.
